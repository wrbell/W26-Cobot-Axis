Project Overview (from Canvas): 

Develop a stepper motor driver that takes commands from a six-axis Universal Robots controller to function as an additional axis of motion 

 

Design Points:

Communication protocol to be used: RTDE (Real Time Data Exchange)
TCI/IP (Transmission Control Protocol/Internet Protocol)
Low-latency, precision, and data-logging make it ideal for this project
Develop & implement a stepper motor driver using a Raspberry Pi Pico based controller which will function as an additional axis to the robot, all communicating over RTDE
Stepper motor will function as extrusion control 
Power the system over Universal Robots Controller 24V power 
Programmed in URScript & the RP2040 chipset’s variant of C++ or MicroPython
Pico-based controller with supply power & signal control to stepper motor, receiving commands & sending feedback/response/status signals to the UR Controller over RTDE
